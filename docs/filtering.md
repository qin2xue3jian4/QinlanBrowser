# 广告过滤

从工具菜单或「设置 → 网页工具 → 广告过滤」进入。网站设置也提供独立开关。更改规则或开关后，刷新网页应用更改。

## 规则来源与更新

默认提供两个开源订阅：

| 订阅 | 来源 | 用途 |
| --- | --- | --- |
| EasyList | <https://easylist.to/easylist/easylist.txt> | 通用网页广告 |
| EasyList China | <https://easylist-downloads.adblockplus.org/easylistchina.txt> | 中文网站补充规则 |

应用只内置订阅地址，不把规则列表写入代码或打包进 APK。首次使用需联网下载；以后使用应用时检查更新，成功下载间隔为四天，失败后一天再试。也可以手动更新、关闭自动更新或禁用某个订阅。更新在后台完成，失败时保留旧文件。

可添加最多八个 HTTPS 订阅，每份最多 8 MB，总缓存最多 16 MB；引擎最多加载 15 万条规则，超出部分计入跳过数量。下载使用独立连接，不携带浏览器 Cookie、浏览记录或页面请求头。原始规则文件及其注释保存在应用私有目录；浏览时仅在本机匹配。

EasyList 项目由 The EasyList authors 维护。EasyList 与 EasyList China 的许可声明见[项目许可](https://easylist.to/pages/licence.html)和[中文规则仓库](https://github.com/easylist/easylistchina)。默认规则声明采用 GPL v3 或 CC BY-SA 3.0（或其后续版本）；其他订阅以维护者声明为准。

## 支持范围

- URL 文本匹配、`*` 通配符、`^` 分隔符、`|` 首尾锚点、`||` 域名锚点。
- `@@` 请求例外、`domain=` 域名限定及排除、`third-party` / `~third-party`、`match-case`。
- `script`、`image`、`stylesheet`、`font`、`media`、`subdocument` 等资源类型选项，仅在 WebView 提供明确类型时生效；类型不明时跳过带类型条件的规则。不会靠文件扩展名猜测请求类型。
- `##` 标准 CSS 元素隐藏、`#@#` 隐藏例外，包括按域名限定和排除。具体 CSS 选择器兼容性取决于系统 WebView。

高级语法（例如正则表达式、scriptlet、重定向替代资源、程序化选择器、`badfilter`、`important`）以及包含未知选项的整条规则均跳过。订阅详情显示可用和跳过数量，不能将其理解为完整 ABP 或 uBlock Origin 兼容。

不会替换主文档，不处理 Service Worker 发出的请求；WebView 也不报告所有重定向后的资源。第三方判断使用包含私有域名的 [Public Suffix List](https://publicsuffix.org/)，表随应用发布更新。其 MPL 2.0 声明保留在资源文件中，完整许可证可在「关于项目」查看。

## 手动屏蔽与排查

选择「手动屏蔽元素」，再点击网页中的目标区域；确认后生成仅适用于该网站的 CSS 规则。点击网页顶部的提示条可取消。此操作需要 JavaScript 和支持消息接口的系统 WebView，不能选择跨域内嵌页面的内部元素。

在「自定义规则」中编辑或删除生成的规则，保存并刷新即可恢复。该页面也支持规则文本导入、导出。最多保存 64K 字符的自定义规则。

「本页拦截记录」展示命中的请求和规则，最多保留最近 100 条，刷新或导航时重置。若网页无法正常登录或播放，可先关闭该网站过滤并刷新，再根据记录调整规则。URL 可能带临时令牌，记录只在内存保存，不写入日志或备份。

选择备份「设置」时，会包含开关、站点例外、订阅配置和自定义规则，不包含下载缓存或拦截记录。
