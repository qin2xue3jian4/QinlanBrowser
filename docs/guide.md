# 使用指南

## 界面语言

支持简体中文、繁体中文和英语，默认跟随系统语言列表，优先使用其中首个支持的语言；没有支持的语言时回退英语。中文会区分简体与繁体，台湾、香港、澳门的中文使用繁体（明确指定简体脚本时除外）。

可在「设置 → 外观 → 语言 / Language」手动选择，或选回「跟随系统」。Android 13 及以上也可通过系统的应用语言设置修改，两处使用同一偏好。Android 8–12 将选择保存在本机。语言偏好不随本地设置备份导出或恢复，但包含在 WebDAV 设置同步中。

切换会刷新浏览器界面并关闭现有操作面板，保留标签和账号空间；不会主动重载已打开的正常网页或退出登录。阅读朗读会停止，可重新进入阅读模式。网页内容、书签/文件夹标题、账号备注、自定义搜索引擎及脚本名称保持原样；系统组件或网站返回的错误信息可能使用它们自己的语言。界面语言不等于网页翻译功能。

## 浏览与搜索

地址栏可输入网址或关键词，支持域名端口、localhost、IPv4/IPv6 和国际化域名。输入至少两个字符时默认匹配本机书签和历史，不向网络发送联想请求；可在设置中关闭。带明确协议的无效地址或包含账号密码的网址不会被转发给搜索服务。点击左侧按钮进入网站设置，可以切换当前标签的搜索引擎，或将其设为默认。更多自定义引擎可在「管理自定义搜索引擎」中命名保存，网址模板使用 `%s` 表示关键词。

底栏提供后退、前进、主页、标签和菜单；没有可跳转历史时，后退或前进变淡并禁用。地址栏未编辑时显示网页标题，点击后显示并选中全部网址。长按标签按钮直接新建标签；标签列表底部提供新建和关闭全部标签，关闭全部前以小弹窗确认。关闭全部后保留一个主页，无痕中则退出并清理会话。「设置 → 工具」提供搜索标签、撤销关闭和关闭其他标签。最近关闭最多保留 10 条、10 分钟，重启后清空，只恢复网址和标题等信息，不恢复网页表单。菜单展开后，再次点击菜单按钮即可收起。

长按网页链接会在当前网页上弹出操作浮层，可在新标签或后台打开、复制及收藏；点击外部或返回即可关闭。关闭由链接打开的标签会优先返回它的父标签。选中文字的菜单增加「翻译」和「页面查找」；页面查找会自动填入选中文字。翻译调用手机已安装的 Android 文本处理服务，优先列出翻译应用；没有服务时提示安装，不自动把文字发给在线服务。

向下浏览时地址栏自动隐藏，向上滑动时恢复。可在「设置 → 外观」中关闭此行为或切换地址栏位置。「设置 → 外观」提供配色、字号和菜单列数设置。

「设置 → 外观 → 右侧翻页按钮」可在网页右侧中央显示四个纯图标按钮：回到顶部、上滑一页、下滑一页、跳到页底。

## 连接安全

「设置 → 网站与隐私 → 仅 HTTPS 模式」默认关闭。开启后 HTTP 地址会自动尝试 HTTPS，HTTP 子资源、框架和下载会被阻止，不自动回退。校园认证页如只支持 HTTP，需要暂时关闭此模式。HTTPS 下载逐次检查重定向，阻止降级到 HTTP；这类下载在完成后选择文件保存位置。

证书异常默认停止连接。在「证书异常处理」中开启询问后，可选择取消、信任一次、信任当前网址。信任一次只用于当前导航；下次访问重新确认。网址例外按 HTTPS 主机、端口和证书 SHA-256 指纹保存，证书改变时再次询问；可从「已信任的证书网址」删除。无痕只允许临时信任。使用例外时网站信息会注明网站身份未可信验证，不把例外当作正常证书。证书例外不导出到备份。

## 截图、分享与网页工具

菜单定制新增「退出浏览器」「网页截图」「浏览器标识（UA）」「网页源码」。退出会关闭浏览器任务；普通标签仍按恢复设置保留，无痕会话会先清理。

截图先选择整个网页或当前区域，然后在子页面拖动框选（默认全部），长页可双指缩放与移动。底部选择 PNG（默认）、JPEG 或 PDF，再取消或保存到选定位置。PDF 为所选截图区域的图像；需要可搜索文字的分页 PDF 可使用原有「打印 / 保存 PDF」。超长页面会降低分辨率以控制内存；视频、受保护内容、尚未加载的懒加载图片取决于 WebView 渲染结果。

分享链接默认先显示标题、网址和二维码，再选择仅网址、标题 + 网址或二维码，最后打开系统分享目标。「设置 → 工具 → 链接分享格式」可设为每次询问或固定格式。

UA 面板显示当前标识，可为当前网站选择手机、电脑或自定义标识，亦可恢复继承默认。源码显示当前页面 DOM，可选择文字和导出 HTML。

地址栏右侧默认为刷新/加载中停止；编辑时可清空输入。可在「设置 → 外观 → 地址栏右侧按钮」改为扫码，二维码也始终位于更多工具中，并支持选择图片识别。网页刷新、页面查找、全屏、无图模式和朗读位于菜单中。

## 设置与菜单

设置分为外观、浏览与搜索、网站与隐私、工具、数据管理和关于。每类内部按用途分组，例如外观按主题、地址栏、主页与菜单排列，阅读字号、行距、亮屏和语速集中在工具的阅读与朗读组。顶部可搜索「字号」「Cookie」「菜单」等关键词，搜索完全在本机进行。单项设置显示当前值、用途和默认值，可恢复此项默认。进入细项再返回会保留搜索词和列表滚动位置；「已修改设置」汇总偏离默认的全局设置。较深的页面右上角可直接返回网页。

「更多工具」「菜单定制」与其他菜单项使用一致的图标网格，可一起调整位置和显隐。「菜单定制」可勾选常用工具，长按拖动或使用上下箭头排序；设置入口始终保留。默认显示 25 项，每行 5 个，「恢复默认菜单」同时恢复按钮顺序和列数。隐藏入口后仍可从设置访问：外观中有菜单定制，工具中有全部工具。每行数量在外观设置中调整。更多工具按阅读与页面、收藏与标签、网站与外观分组，并可搜索。主页列数、顶部标题留白也可在外观设置中调整。

网站设置区分「继承默认」「仅此网站开启」「仅此网站关闭」。网站字号独立于全局字号，提供预览与恢复继承。修改后可点击「应用并刷新」。在「网站与隐私 → 网站例外」可查看、清除覆盖项，不会删除登录数据。编辑网址时保留完整协议前缀，网站面板说明连接是否加密。

## 阅读与打印

在菜单「更多工具 → 阅读模式」打开本地纯文字正文。轻点正文唤出阅读工具浮层，可调字号、暂停/继续/停止朗读、选择语速、导出 TXT 或保存离线；点外部或返回收起工具，继续原来的阅读位置。页头也有阅读工具按钮，长按正文仍可选择文字，滚动不会触发工具。也可把阅读模式添加到常用菜单。正文提取使用 Mozilla Readability，在网页副本上运行，不改变原网页；阅读界面不额外加载图片或运行正文脚本。返回后继续原网页。

阅读模式适合文章，不保证识别论坛、复杂表格、图片或分页内容；超大 DOM 不处理，正文显示最多 20 万字符。朗读使用系统引擎，最多 8 万字符，离开应用暂停。没有文章时会明确提示。设置还提供阅读行距、阅读时保持亮屏和朗读语速；亮屏仅作用于阅读界面。

「离线文章」保存纯文字快照，最多 100 篇 / 20 MB，同一网址再次保存会替换旧内容。支持搜索、离线打开、删除和导出 TXT，不打包进设置备份；卸载应用会删除这些本机文件。

「打印 / 保存 PDF」打印原网页，使用 Android 系统打印面板，可选择保存 PDF；分页与网站打印样式由系统 WebView 处理。清岚不提供服务器转换。

## 主页与书签

通过菜单中的「收藏网页」选择保存到书签、主页或两者，并分别指定文件夹。

主页项目长按至震动后即可拖动。拖到另一项目的两侧用于排序，拖到文件夹中央可移入。展开文件夹后，把网站拖到「移回主页」区域即可移出。长按后不移动、松手，会显示打开、新标签打开、编辑和删除菜单。书签也提供打开和新标签打开；同一主机已配置独立账号或已命名默认账号时，这两个菜单右侧显示小三角，并展开默认账号及各账号名称，直接用所选账号打开，不先加载默认登录。主页图标按顶部对齐，标题长短不改变图标高度。

书签页的「编辑模式」提供复选框、批量移动和删除。按住右侧移动柄可以上下排序；搜索时需先清空关键词才能拖动。删除文件夹时，未选中的子网站移回根目录。

文件夹目前支持一层。书签可导入、导出 HTML；导入时合并去重，外部多层文件夹会展开为一层。

## 历史与下载

历史记录可按关键词搜索，并按最近一小时、今天或最近七天筛选。支持手动多选删除，也可直接删除指定时段的记录。

普通下载使用 Android 系统下载服务，列表自动更新进度与大小，支持搜索以及全部/进行中/已完成/失败筛选。详情显示系统提供的失败原因；部分厂商会将 HTTP 错误归为未知错误，清岚不会把未知原因猜测成具体错误。设置中的「下载仅使用 Wi-Fi」只影响新建任务。完成后可打开或分享文件，失败后可重新下载（重新请求当前 Cookie，不保证旧登录下载仍然有效）。「仅移除清岚记录」保留文件和系统任务；「删除文件及记录」或「取消下载并删除文件」需要确认。下载前展示来源、类型及已知大小；未知大小不会显示成零。

「设置 → 工具 → 支持 Blob 下载」默认关闭，开启后在生成 Blob 的原网页及账号中读取文件，确认文件名并选择保存位置；每文件最多 64 MB，以分块传输控制内存。优先直接读取网页创建的 Blob 对象，兼容禁止 fetch(blob:) 的网站；升级后刷新来源页面以启用文档开始捕获。切换来源页面会取消尚未完成的读取。Blob 和仅 HTTPS 模式的下载使用文件选择器保存，当前不加入系统下载列表。未开启、原网页已关闭或 WebView 不支持桥接时会提示。不支持 HLS/DASH 分片合并及下载队列的暂停管理。

## 浏览习惯与隐私

「浏览与搜索」可设置来自外部应用的链接是否新建标签、主页/书签在当前或新/后台标签打开，以及保留的活动页面数量（2/4/6/8）。降低活动页面数能减少内存占用，但切回旧标签可能重载；总标签上限仍为 50。

「网站与隐私」可关闭新增历史记录；这不会清掉 Cookie、缓存或会话，也不是独立无痕。清理历史会同时清除最近关闭记录及已有网页的后退历史。清理缓存可在没有打开网页时执行。

从「菜单 → 无痕模式」或「设置 → 网站与隐私 → 无痕模式」进入独立会话。原有普通标签暂停，退出后回到原标签；网页可能重新加载，未提交的表单不保证恢复。无痕期间新建、后台打开及网页弹出的标签均属于同一无痕会话，相互共享该会话的登录，但与普通模式隔离。不写入浏览历史、标签恢复文件、最近关闭记录或网站图标缓存；地址建议仅使用已有书签。

地址栏旁的帽子与眼镜图标可退出，菜单也有「退出无痕」。关闭最后一个无痕标签会直接退出并清理全部无痕网站数据。切到后台不会自动退出，返回后可以继续；无痕期间从其他应用打开的链接也在当前无痕会话中处理。屏幕截图与最近任务中的页面预览受到保护。输入框会请求输入法停止个性化学习，但第三方输入法是否遵守取决于它自身。

无痕使用系统 WebView 的独立配置隔离 Cookie、缓存和网站存储，退出时异步清理。它并非纯内存运行：会话期间内核可能写入设备存储；若系统强行终止进程，残留配置在下次启动时清理，无痕标签不会恢复。不提供取证级安全擦除。WebView 缺少多配置或清理能力时会提示更新，不会以单纯关闭历史记录代替隔离。

无痕中不执行用户脚本，不提供普通 Cookie / 密码管理或保存新的站点设置，沿用已有浏览偏好。主动下载的文件及系统下载记录、书签、主页收藏、离线文章、导出与分享内容仍会保留，保存前有相应说明。无痕不能隐藏 IP，也不能阻止网站、网络提供者或已登录账号识别你。

网页唤起外部应用只响应前台页面中的用户点击，可选择每次询问或始终阻止。网站的相机/麦克风/位置询问与媒体自动播放均可分别控制；使用前还需系统权限或网站自身兼容支持。

## 密码与备份

### 网站多账号

打开网站后，点击地址栏左侧的「网站设置 → 网站账号」，选择「添加账号」，填写「个人」「工作」等备注。清岚会为它创建独立登录空间，在当前标签打开网站首页；首次需重新登录，也可在该空间的 Cookie 管理中导入已有凭据。原有登录保留在默认账号中，「命名默认账号」可以单独给这个网站的原有登录设置备注。

以后点击地址栏上的账号名称即可切换。切换只重新加载当前标签，未提交的输入与此标签的后退历史会丢失；其他标签保持原有账号。同一网站可以同时打开多个账号。「设置 → 网站与隐私 → 网站多账号」提供重命名、新标签打开和删除。名称最长 24 个字符，同一网站不允许重名；最多保存 20 个独立账号。

每个账号空间隔离 Cookie、网站缓存及本地存储，登录时涉及的其他域名也在该空间中处理，无需手工指定关联域名。网站名称用于整理账号列表：在账号标签中导航到其他网站、通过链接打开新/后台标签和网页弹窗，仍沿用该空间；不会按域名自动跳回默认登录。新建空白标签使用默认账号。地址栏和标签列表显示账号名称，长名称可在切换面板查看。

关闭标签不会删除登录空间，标签恢复和撤销关闭保留账号归属；无痕使用另一套临时数据，退出后回到之前账号。下载使用来源账号的 Cookie，重试也沿用原账号；原账号已删除时需要回网页重新发起。Cookie 编辑与导入导出针对当前打开的账号，面板会显示名称。

账号空间不等于无痕：浏览历史、书签、设置和密码管理仍然共用。名称只是备注，清岚不自动识别网站用户名；网站可能让凭据过期，届时需要重新登录。数据保留依赖 WebView 正常写入，刚写入就被系统强行杀死的内容不保证已落盘。账号空间及默认备注不包含在设置备份中，没有云同步。

删除账号空间会关闭它的所有标签，清理其中所有网站数据；其他账号、书签、历史与下载文件保留。已加载的内核配置元数据可能在下次启动删除，异常中断后也会重试清理。常规「清理浏览数据」中的缓存、Cookie 和网站存储仅针对默认账号，独立账号从多账号管理中删除。每个空间的缓存和数据库会额外占用设备存储，活动页面仍受内存设置限制。

### 保存密码

「设置 → 数据管理 → 密码管理」支持手动新增密码，也可以读取当前表单中已填写的账号密码，在确认后保存。填入操作仅用于完全匹配的 HTTPS 站点，不会自动提交登录。目前不支持跨域 iframe、多步骤登录和通行密钥。

「备份与恢复」可分别选择主页、书签、设置和已保存密码：

| 内容 | 格式 | 恢复方式 |
| --- | --- | --- |
| 主页、书签、设置 | JSON | 替换选中的分类 |
| 包含已保存密码的备份 | 加密 `.qlb` | 密码按站点和账号合并；其他选中分类替换 |

加密备份采用 AES-256-GCM，使用 PBKDF2-HMAC-SHA256 从导出密码派生密钥。导出密码至少四个字符，建议使用更长的密码。忘记密码后无法解密备份。

备份不包含 Cookie、历史、下载记录、标签会话和用户脚本。密码库不能从网站 Cookie 中还原账号密码。

## WebDAV 设置同步

打开「设置 → 数据管理 → WebDAV 设置同步」，填写已存在的 HTTPS WebDAV **目录地址**、账号和应用密码，然后保存配置。坚果云服务器地址为 `https://dav.jianguoyun.com/dav/`，需要在其后填写已存在的同步文件夹及子目录路径（根地址不能直接上传文件）；密码应使用[坚果云第三方应用授权密码](https://help.jianguoyun.com/?p=2064)。各设备使用同一目录即可共享设置文件 `qinglan-settings.json`。

- 「上传本机设置」检查远端后询问是否创建或替换文件；确认时上传此次操作开始时的本机设置快照。
- 「检查连接 / 下载设置」读取远端并校验格式，确认后替换本机可同步设置；远端未包含的设置恢复默认值。远端文件不存在时可以上传，目录是否存在及写入权限以实际上传结果为准。
- 同步包含浏览器与网站设置、主题配色、主页显示偏好、菜单、自定义搜索引擎、过滤订阅/手动规则和界面语言。选择「跟随系统」的设备继续使用各自的系统语言。
- 不同步主页收藏、书签、密码、Cookie、历史、标签、下载记录、账号空间、证书信任、用户脚本或其存储。WebDAV 凭据在本机通过 Android Keystore 加密，与备份及同步文件分开。

设置文件以明文 JSON 存在你的服务器中，单个文件最多 1 MB。同步按按钮手动执行，没有后台自动同步。上传使用 ETag 条件请求；其他设备在检查后改动文件时会提示重新操作。服务器未提供可用的 ETag 时，只能创建新文件或下载，无法覆盖已有文件；支持标准强 ETag 以及坚果云返回的不带引号的版本标识。连接验证使用系统 HTTPS 证书校验，服务器重定向时需填写最终目录地址。删除本机配置会移除保存的地址和凭据，远端文件仍保留。

确认上传后会再次读取远端，拒绝覆盖确认期间发生的变化。坚果云忽略创建新文件时的 `If-None-Match: *` 条件，因此首次上传的最后检查与实际写入之间仍有短暂竞态；首次设置请先由一台设备完成上传，再在其他设备下载。已有文件的更新使用实测可用的 `If-Match` 版本检查。

## Cookie

先打开目标网站，再从菜单进入「Cookie 管理」。支持 Cookie-Editor JSON 的导入、导出、编辑和删除，仅操作清岚自己的 WebView 数据。

读取范围为当前网址可访问的 Cookie，不同路径和子域应分别访问。导入按名称、域名和路径合并；无关域名、过期数据及暂不支持的分区 Cookie 会被跳过。网站仍可能要求重新登录或验证。

**Cookie 文件是明文登录凭据。** 请妥善保存，不要上传到公开仓库或反馈附件。

## 用户脚本

在「设置 → 工具 → 用户脚本」导入 `.user.js`、粘贴源代码或从网址安装。可以直接浏览 Greasy Fork，点击「安装此脚本」进入原生预览；也可输入脚本页面网址。安装前查看源码、匹配范围、授权和联网声明，新脚本默认关闭，启用后刷新网页生效。同名且 namespace 相同的脚本可手动更新，保留脚本 ID、启用状态和配置。

支持范围：

- 网址规则：`@match` 支持中文域名（IDN）、域名通配符和端口，`@include` 通配符与 `/正则/`、`@exclude`、`@exclude-match`；未声明匹配规则时默认匹配 HTTP/HTTPS 网页。
- 执行时机：`document-start`、`document-body`、`document-end`、`document-idle`。匹配的 HTTP/HTTPS iframe 默认运行，`@noframes` 限定顶层网页；about:blank/srcdoc 不注入。
- 页面接口：`GM_addStyle`、`GM_addElement`、`GM_log`、`GM_info`、`unsafeWindow`，以及对应 `GM.*` 形式。
- 配置存储：get/set/delete/listValue(s)、批量存取、值变更监听，支持同步旧接口和 Promise 形式的 `GM.*`。配置按脚本保存，可跨网站使用，删除脚本也删除其配置。标签会话数据在对应 WebView 存活期间保留，视图销毁/重建会丢失。
- 网络：`GM_xmlhttpRequest` / `GM.xmlHttpRequest` 支持文本、JSON、ArrayBuffer、Blob、HTML 文档响应及常见完成/失败/超时回调。目标和每次重定向都检查 `@connect`；默认仅当前主机，明确声明的域名包括子域，`*` 允许任意 HTTP/HTTPS 主机。不会自动附带浏览器登录 Cookie，不允许设置 Cookie/Host/Origin/Referer 等保留请求头，HTTPS 不向 HTTP 降级，跨 origin 重定向不转发 Authorization。遵守浏览器「仅 HTTPS」设置。
- 依赖：安装时按声明顺序下载 `@require`，缓存 `@resource` 文本及 data URL，支持资源读取接口；运行时使用本机缓存。联网依赖仅通过 HTTPS 下载，也支持 data URL 内联依赖；校验支持 MD5、SHA-1/256/384/512 的十六进制和 Base64 写法。导出 `.user.js` 仅含源代码，重新安装会重新获取依赖。
- 命令：`GM_registerMenuCommand` / `GM_unregisterMenuCommand` 的按钮显示在当前网页的用户脚本面板。支持通过原生浏览器前台/后台打开标签的 `GM_openInTab`，保持来源账号，并可关闭该脚本打开的标签；剪贴板写入检查 GM_setClipboard 授权；支持 getTab/saveTab/getTabs 的标签会话数据和 window.onurlchange。

脚本与网页共享 JavaScript 环境，没有完整扩展沙箱；`@sandbox` 标记不会创建隔离环境。无痕不执行脚本。暂不支持自动更新、`GM_download`、通知、Cookie 管理和 `@unwrap`；声明未实现授权的脚本会明确拒绝安装。

上限：50 个脚本，单脚本源代码 2 MB，单次网络响应 4 MB，每个脚本源代码与依赖合计 8 MB，安装库合计 32 MB；单脚本配置 1 MB、全部配置 8 MB。脚本配置与源代码不包含在浏览器设置备份中。旧 WebView 不支持文档开始注入时，start 脚本无法启用，其余脚本在加载完成后运行；缺少消息桥能力时存储、网络和命令不可用。页面效果仍需在目标网站验证，能安装不代表完整功能兼容。

## 其他限制

- 最多同时打开 50 个标签；重启后恢复标题和网址，不保证恢复表单及滚动位置。
- 网站摄像头、麦克风和位置请求仅面向前台 HTTPS 同源页面，先进行网站确认，再按需申请 Android 权限。未知资源类型、跨源嵌入和后台请求会拒绝；位置只申请大致位置。不保存网站永久许可。询问开关不等于自动授权。
- 网页深色效果取决于网站样式及 WebView 能力。

## 广告过滤

通过工具菜单的「广告过滤」管理规则、查看本页拦截记录或手动屏蔽元素。默认规则来自 EasyList 和 EasyList China，首次使用需联网下载。遇到误拦截可在网站设置中关闭该网站的过滤，再刷新网页。更多操作见[广告过滤指南](filtering.md)。

## 网页资源

工具菜单中的「网页资源」按标签页收集视频、音频、图片和播放列表，可复制地址、直接下载或用外部应用打开。先播放媒体再扫描通常更容易发现资源。播放列表和 Blob 的处理方式见[网页资源指南](resources.md)。

## 帮助与反馈

「设置 → 关于 → 帮助与排错」提供网页、下载、权限和离线数据的说明，以及系统权限入口。可复制仅含应用/Android/WebView版本等信息的诊断文本，不包含网址、Cookie、密码或历史。复制不会自动发送反馈。网页连接或渲染进程出错时会提供重新加载、编辑网址和返回主页，避免无限自动重载。
