# 网页资源

打开网页后，从工具菜单进入「网页资源」。建议先播放音视频，再打开列表；需要时点击「重新扫描」。

## 分类与操作

默认显示音视频和播放列表；图片、媒体分片与 Blob 可在「分类」中单独查看。每个标签页最多保留 300 条，优先保留音视频和播放列表。条目显示资源名称、类型和域名，详情页可查看完整地址。

- **普通 HTTP/HTTPS 资源**：复制地址、在新标签页打开、下载，或交给外部应用。
- **HLS / DASH 播放列表**：复制地址或交给支持相应格式的下载器、播放器。清岚的「下载播放列表」只保存清单，不下载或合并分片。
- **媒体分片**：可保存单个分片，但它通常不是完整文件。
- **Blob 媒体**：可在设置中开启「支持 Blob 下载」，从生成它的原网页读取文件（最大 64 MB）并选择保存位置。MediaSource 流式媒体不一定对应可读取的完整 Blob；这类资源可查找相应的 HTTP 资源或播放列表。

直接下载使用 Android 系统下载服务，并携带该地址当前的 Cookie、浏览器标识以及发现资源时的来源页。下载前可以修改文件名。地址可能过期，或需要其他认证信息，发现资源不代表一定能下载。

外部应用仅收到 URL 和资源类型，不自动传递 Cookie。清岚不提供 DRM 解密、HLS/DASH 分片合并、转码或下载队列暂停管理。

## 收集方式与数据

资源来自 WebView 请求、页面媒体元素、资源加载记录，以及 fetch/XHR 响应的类型信息。无需扩展名的音视频也可能通过页面声明或响应类型识别。不主动探测未知地址，不读取响应正文，不记录 Cookie 或请求体。

动态插入的媒体、图片及支持消息接口的内嵌页面也会参与收集。被广告过滤拦截的请求不会进入原生资源收集器，但网页仍可能在元素或加载记录中保留该地址，因此资源列表不代表请求一定成功。

列表仅保存在内存中，按标签页隔离，页面导航或刷新时重置，不导出到备份。「清空列表」只清空当前记录；后续加载仍会收集。「收集网页资源」开关可停止收集，更改后刷新网页可完全启用或停用页面观察。该开关随设置备份保存。

完整观察需要启用 JavaScript 和较新的系统 WebView。旧内核会退回请求地址识别与当前主页面扫描。Service Worker、部分重定向、加密播放器或未开始加载的资源可能无法发现。
