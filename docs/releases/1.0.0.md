清岚 1.0.0 是首个正式版本：基于系统 WebView 的轻量 Android 浏览器，支持 Android 8.0 及以上版本。

### 主要功能

- 可整理的主页与书签文件夹、标签搜索、撤销关闭、下载管理及二维码扫描。
- 无痕浏览与网站多账号，为不同登录状态提供独立的网站数据空间。
- 阅读模式、离线文章、系统朗读、文字导出和打印 / 保存 PDF。
- 广告规则订阅、网站例外、手动元素屏蔽和网页资源识别。
- 用户脚本安装预览、授权查看及本地管理。
- 可搜索的分类设置，支持网站独立设置、菜单定制、主题配色和自定义搜索引擎。
- 按需备份与恢复；包含已保存密码的备份使用密码加密。
- HTTPS WebDAV 设置同步，支持手动上传与确认恢复；凭据在设备本机加密保存。
- GitHub 正式版更新检查，支持自动检查、手动检查和更新说明。
- 简体中文、繁体中文和英语界面，默认跟随系统。

### 安装与升级

下载 **qinglan-1.0.0.apk** 后按系统提示安装。**SHA256SUMS** 用于核对安装包的 SHA-256。

从旧版覆盖升级需要相同的应用签名。调试包可能使用不同签名；卸载会删除应用私有数据，请提前备份需要保留的内容。使用可用且较新的 Android System WebView；无痕与多账号需要 WebView 支持数据隔离与清理。

### 数据与功能范围

清岚无需注册账号。浏览数据保存在设备本地；WebDAV 仅同步设置与界面语言，不包含书签、密码、Cookie、历史或标签。Cookie 导出可能包含登录凭据，请勿公开分享。

用户脚本支持基础页面扩展，尚不兼容完整的 Tampermonkey API。网页资源识别不提供 HLS/DASH 分片合并或 DRM 解密；无痕不会隐藏网络身份。
