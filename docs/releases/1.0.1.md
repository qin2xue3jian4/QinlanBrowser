清岚 1.0.1 修正仓库改名后的 GitHub 地址。

### 修复

- 更新检查 API、项目主页、发布页和反馈地址改为 `qin2xue3jian4/QinlanBrowser`。
- 更新使用指南、隐私说明和发布文档中的仓库链接。
- Android 版本号递增为 18，继续使用 1.0.0 的正式发行签名。

### 安装与升级

支持 Android 8.0 及以上版本，需要可用的 Android System WebView。下载 **qinglan-1.0.1.apk** 安装；**SHA256SUMS** 用于校验安装包完整性。

正式版 1.0.0 可直接覆盖升级，保留应用数据。旧版更新检查不会跟随仓库改名重定向，请从本发布页下载并安装本次更新。

仓库保持私有时，应用的匿名 GitHub 更新检查无法读取其 Release，需登录 GitHub 手动下载。安装包不包含仓库访问凭据。
