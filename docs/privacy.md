# 数据与隐私

清岚无需注册浏览器账号。书签、主页收藏、浏览历史、设置、离线文章、用户脚本和网站账号空间保存在设备上。已保存密码与 WebDAV 凭据使用 Android Keystore 加密；网页 Cookie 和网站存储由系统 WebView 管理。

## 网络连接

| 功能 | 连接对象 | 发送内容与控制方式 |
| --- | --- | --- |
| 网页浏览 | 访问的网站及其资源服务 | 页面请求及对应账号空间的 Cookie，遵循网站设置 |
| 搜索 | 所选搜索引擎 | 确认提交的搜索词；地址栏本地建议不联网 |
| 广告规则更新 | 启用的订阅地址 | 请求规则文件，可关闭订阅或自动更新 |
| 应用更新检查 | GitHub 公开发布 API | 请求最新正式版信息，不附带浏览记录、设置、账号或凭据；默认每天最多一次，可关闭 |
| WebDAV 同步 | 自行配置的 HTTPS 服务器 | 仅在手动操作时发送服务器认证信息和设置文件 |
| 用户脚本及依赖 | 安装时声明的资源地址、脚本获准请求的服务 | 安装预览显示授权和联网范围，启用前应确认脚本来源可信 |

网络服务会接收到建立连接所需的信息，例如 IP 地址。搜索引擎、网站、订阅服务、GitHub 和 WebDAV 服务的数据处理由各自提供方负责。清岚不内置广告或使用统计 SDK。

## 同步、导出与分享

WebDAV 设置文件为明文 JSON，包含浏览器与网站设置、菜单、自定义搜索、过滤配置和界面语言；不包含书签、主页收藏、密码、Cookie、历史、标签或账号空间。服务器凭据仅在本机加密保存，不写入同步文件或备份。

包含密码的备份需要设置导出密码并加密。Cookie 导出文件可能包含明文登录凭据。链接分享、文件导出和诊断信息复制由用户主动操作；分享前应检查其中是否含有私人数据。应用内生成的诊断摘要不包含网址、Cookie、密码或历史。

## 权限与清理

相机用于扫码及经确认的网站请求；麦克风和大致位置仅在前台 HTTPS 网站请求并经确认后使用。下载和导出使用 Android 提供的文件选择或下载服务。

可在「清理浏览数据」中选择清理历史、缓存、默认账号 Cookie 和网站存储；独立网站账号请从「网站多账号」删除。卸载应用会移除应用私有数据，主动保存到外部位置的下载和导出文件需自行删除。关闭历史记录不会清除 Cookie 或已有历史。

无痕会话隔离网站数据，退出后清理；系统强行结束进程时可能暂留引擎文件，下次启动会继续清理。无痕不会隐藏网络身份，也不会删除主动保存的下载、书签或导出文件。
