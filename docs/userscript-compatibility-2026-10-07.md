## 为什么安装成功仍可能只有部分作用

- 原生请求不自动携带网站 Cookie，Cookie/Host/Origin/Referer 等保留头目前拒绝。432382、424701、433020 等源码存在特殊请求头分支，因此这些分支可能失败；页面本身的同源 fetch/XHR 则仍走网页正常登录环境。
- 438657 未声明 @connect，而其部分请求访问其他域，默认同主机限制会拒绝这些请求；第三方解析服务本身是否有效也不能由浏览器兼容层保证。
- 网课/题库脚本的界面和配置较容易运行；实际查询、提交及长时间自动流程还依赖服务接口、登录状态、自动播放设置和后台视图是否保留。
- 视频脚本的倍速、画面调整比手机快捷键、全屏/PiP、跨域截图、完整下载更容易可用。getTab 等会话数据在 WebView 销毁/重建后会丢失；后台视图被回收也会中断正在运行的脚本。
- 25718 的现行代码只有删除提示，没有原来的功能。这是明确的“能安装但无原功能”，无需通过增加浏览器 API 修复。
- 引擎与网页共享 JS 环境，尚无完整扩展沙箱，@sandbox 标记不会创建隔离世界。about:blank/srcdoc 不注入。现代 fetch 流、上传进度、完整通知/下载、Cookie、webRequest 等仍不提供。
- 网络请求限制响应 4 MB，脚本配置限制每脚本 1 MB；abort 主要停止 JS 回调，已经开始的传输不保证立即结束。

## 手机调试与收尾

界面回归使用专用测试设备。调整亮屏或充电唤醒设置前应记录原值，测试结束后恢复；设备锁屏或 USB 断开会影响结果。

热门脚本测试使用独立安装库并在结束后删除，第三方脚本都未启用；合成安装脚本及测试标签也已清理，正常脚本、Cookie、收藏不会因此删除。
