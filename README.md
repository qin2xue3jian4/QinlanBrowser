# 清岚

轻量 Android 浏览器，基于系统 WebView。把常用浏览功能、可整理的主页和站点管理放在一个小巧的安装包里。

[下载安装](https://github.com/qin2xue3jian4/AndroidBrowser/releases) · [使用指南](docs/guide.md) · [构建与开发](docs/development.md) · [发布指南](docs/releasing.md)

## 功能

- **浏览**：本地地址建议、后台打开、标签搜索与撤销关闭、批量关闭其他标签、下载搜索/状态筛选/重试、页面查找、电脑模式、无图模式、全屏和二维码扫描。
- **无痕**：独立 Cookie 与网站存储，不记录历史或恢复无痕标签；退出时清理会话，保留原有普通标签。需要 WebView 支持多配置隔离与数据清理。
- **网站多账号**：为个人、工作等登录状态命名，按标签切换独立账号空间；其他标签不变，可同时打开同一网站的多个账号。
- **阅读**：本地正文提取、离线文章、独立字号/行距、系统朗读与语速控制、正文 TXT 导出，以及系统打印 / 保存 PDF。
- **收藏**：主页与书签文件夹、拖动排序、批量整理，同一次收藏可保存到书签和主页。
- **自定义**：可搜索的分类设置及已修改汇总、全局与单网站字号、主页密度、地址栏位置/按钮、主题配色、菜单显隐与排序、多个搜索引擎、内存与下载网络偏好。
- **广告过滤**：EasyList 与 EasyList China 订阅、网站例外、拦截记录和手动元素屏蔽。
- **网页资源**：音视频、图片和播放列表识别，直链下载及外部应用打开。
- **站点管理**：独立网站设置、前台 HTTPS 网站权限确认、外部应用跳转控制、Cookie 导入导出、手动保存与填入密码、轻量用户脚本。
- **备份**：按需导出主页、书签、设置和已保存密码；包含密码的备份使用密码加密。

## 安装

需要 **Android 8.0 或更高版本**，以及可用的 Android System WebView。

在 [Releases](https://github.com/qin2xue3jian4/AndroidBrowser/releases) 下载 APK 后安装。更新时使用相同来源、相同签名的安装包即可覆盖升级。

清岚不打包浏览器内核。网页兼容性随系统 WebView 更新，建议保持其为较新版本。部分功能也依赖系统组件，例如朗读需要可用的语音引擎。

## 数据与兼容性

书签、历史、设置和密码保存在设备本地，无需清岚账号。密码在本机加密存储；导出密码备份时，需要另外设置解密密码。

Cookie 导出文件包含明文登录凭据。用户脚本能够读取和修改匹配网页的内容，请仅导入可信文件。使用方式及支持范围见[使用指南](docs/guide.md)。

目前不提供云同步。无痕不会隐藏 IP；主动保存的下载、书签和离线文章仍会保留。用户脚本支持基础页面修改，并不兼容完整的 Tampermonkey API。

## 反馈

欢迎通过 [Issues](https://github.com/qin2xue3jian4/AndroidBrowser/issues) 提交问题或建议。网页兼容问题请附上网址、Android 版本、WebView 版本和复现步骤；不要上传 Cookie、密码或含有这些数据的备份。

## 过滤与资源识别

广告规则采用可更新订阅，不随 APK 打包；首次使用需要下载。清岚支持常用过滤语法，不等同于完整 uBlock Origin 引擎。资源嗅探可发现普通媒体和播放列表，暂不提供 HLS/DASH 合并及 DRM 解密。具体操作与兼容范围见[广告过滤](docs/filtering.md)和[网页资源](docs/resources.md)。
